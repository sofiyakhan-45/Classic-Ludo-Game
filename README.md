🎲 Classic Ludo Game

A simple and interactive Ludo Game made using HTML, CSS and JavaScript.

This project includes a responsive Ludo board that works on both mobile and laptop screens. Players can enter their names, roll the dice and move their tokens according to the dice number.

Features
🎲 Dice rolling with animation
👥 4 players — Red, Green, Yellow and Blue
✏️ Players can enter their own names
🟢 Token movement on the board
6 आने पर token home se bahar aa sakta hai
⭐ Safe cells
💥 Opponent token ko capture karna
🏆 Winner detection
🔄 Restart game option
📱 Mobile responsive design
💻 Laptop/Desktop responsive design
🎯 Glowing effect for movable tokens

CSS

How to Play
Enter the names of the players.
Click ROLL to roll the dice.
If you get 6, you can bring a token out.
Click the glowing token to move it.
Move your tokens around the board.
Capture opponent tokens when possible.
Try to move all 4 tokens to the center.
The player who gets all 4 tokens to the center wins.
