# 🎲 Classic Ludo Game

A simple and interactive Ludo Game made using HTML, CSS and JavaScript.

This project includes a responsive Ludo board that works on both mobile and laptop screens. Players can enter their names, roll the dice and move their tokens according to the dice number.

## Features

- 🎲 Dice rolling with animation
- 👥 4 players – Red, Green, Yellow and Blue
- ✏️ Players can enter their own names
- 🟢 Token movement on the board
- 🎯 Get 6 to bring a token out
- ⭐ Safe cells
- 💥 Capture opponent tokens
- 🏆 Winner detection
- 🔄 Restart game option
- 📱 Mobile responsive design
- 💻 Laptop/Desktop responsive design
- ✨ Glowing effect for movable tokens

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Play

1. Enter the names of the players.
2. Click **ROLL** to roll the dice.
3. If you get **6**, you can bring a token out.
4. Click the glowing token to move it.
5. Move your tokens around the board.
6. Capture opponent tokens when possible.
7. Try to move all 4 tokens to the center.
8. The player who gets all 4 tokens to the center wins.
